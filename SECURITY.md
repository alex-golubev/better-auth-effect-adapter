# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| 0.x     | No        |

## Reporting a vulnerability

Please don't open a public issue. Report it privately through a [GitHub security advisory](https://github.com/alex-golubev/better-auth-effect-adapter/security/advisories/new).

Include:

- the affected versions of `better-auth-effect`, `effect`, `better-auth` and the `@effect/sql-*` driver;
- the database;
- how to reproduce it, and what an attacker gains.

Vulnerabilities in Better Auth itself belong to [Better Auth](https://github.com/better-auth/better-auth/security).
